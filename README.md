# Hassan Essam Mohamed | Portfolio

Professional portfolio for Hassan Essam Mohamed, a Railway Technology student. The site presents his education, practical railway training, skills, student projects, and languages.

The site is built with static HTML, CSS, and JavaScript and has no build step. Profile photographs and the railway background are stored in `assets/`, and project photographs are stored in `assets/projects/`.

## Deploy to GitHub Pages

In the repository, open **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish `index.html` and the referenced assets.

## Deploy to Vercel

Import the repository into Vercel using the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` contains these settings; no dependencies are required.
